# Job Tracker API

A REST API built with FastAPI to manage and track job applications.

## Features

- Create job applications
- View all applications
- View an application by ID
- Update applications
- Delete applications
- Filter applications by status
- Input validation
- SQLite database with SQLAlchemy
- Automated API testing with pytest

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- Pytest
